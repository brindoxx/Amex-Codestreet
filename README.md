# Amex Intelligate — JS React (Vite)

This repository was converted from a TypeScript/TSX setup to a JavaScript/JSX Vite React project.

Structure:

- `index.html` — Vite entry
- `src/` — application source
  - `main.jsx`
  - `App.jsx`
  - `components/` — UI components
  - `pages/` — page-level components

To run locally:

```bash
npm install
npm run dev
```
